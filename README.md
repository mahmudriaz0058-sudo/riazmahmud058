# Syed Riaz Mahmud — Research Portfolio

Static site: `index.html` + `images/`. No build step.

## Publish on GitHub Pages
1. Create a public repository named `<your-username>.github.io` (or any name).
2. Upload **everything in this folder** (keep the `images` folder structure).
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
4. The site goes live at `https://<your-username>.github.io/` in 1–2 minutes.
